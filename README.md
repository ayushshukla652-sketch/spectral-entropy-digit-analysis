# Spectral Entropy as a Multiscale Diagnostic

This repository contains code and data used in the paper:

**"Spectral Entropy as a Multiscale Diagnostic for Digit-Sequence Complexity"**

## Contents

- `power.py` – script to compute Shannon and spectral entropy
- `spectral_entropy_analysis.tex` – LaTeX manuscript
- `plots_new/` – generated figures

## Reproducibility

To reproduce results:

```bash
pip install -r requirements.txt
python main_analysis.py
